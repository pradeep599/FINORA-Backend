# FinPulse AI — Backend (Spring Boot 3 + MySQL + JWT)

## Setup (Eclipse IDE)
1. File -> Import -> Maven -> Existing Maven Projects -> select `FinPulseAI_Backend`.
2. Update MySQL username/password in `src/main/resources/application.properties` if needed.
3. Run `FinPulseApplication.java`. Database `finpulse_ai_db` and demo data (`demo@finpulse.ai` / `Demo@123`) are auto-created on startup.
